SÜRÜM YÜKLEME v1.0.3 - KLASÖR YAPISI
====================================

Kaynak Kod
----------
Geliştiriciler için uygulama kaynakları, ortak bileşenler, test projesi,
Easy Installer/UUU araçları ve yayın profilleri bulunur.

Hedef saha bilgisayarında kaynak kod klasörüne ihtiyaç yoktur.

docs
----
Kurulum ve saha hazırlığı, mimari/iş akışı, sorun giderme rehberleri ve
uygulama ekran görüntüleri bulunur.

Uygulama
--------
Yerel geliştirme bilgisayarındaki doğrulanmış yayın çıktısıdır. Git tarafından
izlenmez. Saha dağıtımı için bu klasörü elle kopyalamak yerine GitHub Releases
bölümündeki Windows saha paketi kullanılmalıdır.

GitHub Releases
---------------
Hedef bilgisayara taşınacak sürümlendirilmiş ZIP paketi, EXE ve SHA256
doğrulama dosyaları burada yayımlanır.

ÖNEMLİ
------
Gerçek yazılım paketleri, logs klasörü, Settings.json, parolalar ve bilgisayara
özel ağ/donanım ayarları GitHub deposuna eklenmemelidir.
